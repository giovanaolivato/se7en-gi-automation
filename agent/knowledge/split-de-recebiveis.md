# Split de recebíveis

Ferramenta **exclusiva do [F3/Cappta](produtos/f3-cappta.md)**. O cliente
cadastrado no F3 **não sai configurado automaticamente no split** — é
necessário configurar manualmente.

> Este arquivo é sobre **como configurar** o split no app Empresas. Se a
> pergunta for sobre **por que usar** (benefício tributário, se é legal,
> como convencer o cliente) → ver
> [produtos/split-fundamentacao-e-vendas.md](produtos/split-fundamentacao-e-vendas.md).

## Como configurar

O licenciado deve enviar vídeos ou auxiliar presencialmente o estabelecimento:

1. Acessar o **app Empresas**.
2. Clicar em **Split**.
3. Selecionar **acúmulo de recebíveis**.
4. Digitar **28** (dias) nas opções.
5. **Salvar.**

> A configuração vale a partir do **próximo dia útil** — só as vendas do
> próximo dia útil em diante ficam acumuladas pelos 28 dias.

Link de apoio com passo a passo completo (primeiro acesso ao app Empresas,
download dos apps, configuração do acúmulo, cadastro de beneficiário Pix e
agendamento de boleto):

🔗 https://se7en-onboarding.pages.dev/

## Regra de horário para agendamento

- Agendamento feito **até 14h00** → pode ser agendado para o dia atual,
  liquidação ocorre no mesmo dia.
- Agendamento feito **após 14h00** → só pode ser agendado para os próximos
  dias úteis.

## Problemas com split

- Problemas de **cadastro/agendamento** (beneficiário, agendamento Pix,
  agendamento boleto, acúmulo de recebíveis) → fila **Back Office - split -
  problemas cadastrais**.
- Problemas de **pagamento** (recusas de boleto, devoluções, liquidações na
  conta do EC) → fila **Back Office - split - problemas de pagamentos**.

Ver detalhes em [chamados/back-office.md](chamados/back-office.md).
