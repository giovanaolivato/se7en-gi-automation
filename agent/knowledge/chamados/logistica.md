# Filas — Logística

Trata inventário de máquinas, periféricos, envios e manutenção.

## Cadastral - solicitação de inclusão/transferência de inventário
Qualquer ajuste no inventário de equipamentos ou inclusão de novo
equipamento/máquina.

## Manutenção - manutenção de POS
Máquinas que precisam de manutenção presencial devem ser enviadas para a
logística/terminal logístico. O licenciado deve **abrir o chamado antes de
enviar a máquina pelos Correios** para receber o código de envio — as
orientações e etiqueta são enviadas pelo próprio chamado. Todas as
instruções ficam registradas ali.
