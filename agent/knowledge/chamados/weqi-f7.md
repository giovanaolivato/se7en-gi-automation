# Fila — WeQi (F7)

⚠️ **Só use esta fila se o licenciado confirmou que é F7/WeQi.** Vários
problemas daqui (ex: skin/logo) também existem como fila **geral** em
[back-office.md](back-office.md) — se o licenciado não disse o fornecedor,
use a fila geral, não assuma WeQi só porque o sintoma bate.

Toda solicitação relacionada ao **fornecedor 7 (WeQi)** cai nesta fila
específica, fora da divisão padrão por área. No portal, pesquise "WeQi" e
selecione o problema que mais se encaixa. Cobre:

- Problemas no Pix
- Juros / taxa ao portador
- Problemas com transação débito/crédito
- Problemas com a máquina do F7
- Lentidão na aplicação da máquina
- Atualização de Skin/logo
- Problemas com os dados móveis do chip

Ver também [../produtos/f7-weqi.md](../produtos/f7-weqi.md).
